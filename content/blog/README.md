# Studio blog

Essays for revealuistudio.com. The registry in `registry.ts` decides what is public.

Published posts render at `/blog` and `/blog/<slug>`. Held posts stay in this directory with a `todo` that names the path they moved from (`RevealUIStudio/revealui docs/blog/<file>`). They are off the index until a brand pass removes outside vendor names.

Redirects from the old docs URLs are listed in `docs/BLOG-CUTOVER.md`. The docs host has to send those. This repo only covers numbered paths requested on revealuistudio.com.
