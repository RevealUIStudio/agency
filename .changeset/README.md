# Changesets

Version history for `@revealui-studio/agency`. This package is private and is not published to npm.

Add a changeset on the working branch and merge that branch to `test`. Before `test` promotes to `main`, run `pnpm changeset:version` and commit the result.

`pnpm changeset:version` bumps `package.json` and `CHANGELOG.md`. It does not publish.
